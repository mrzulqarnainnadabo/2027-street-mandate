# Evidence metadata contract — v1.0.0

Every item used to support a Civic Brain claim must be representable as an EvidenceRecord.

## Source types

official_publication | official_dataset | published_research | community_submission | media_report | institutional_announcement | independently_verified | unverified_claim | historical

## Rules

1. Official ≠ complete.
2. Announcement ≠ implementation.
3. Allocation ≠ expenditure ≠ successful delivery.
4. Community submissions ≠ prevalence estimates.
5. Citations must identify evidence items, not only generic homepages.
