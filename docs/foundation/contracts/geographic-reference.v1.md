# Canonical geographic reference — v1.0.0

Hierarchy: Nigeria → State/FCT → LGA → Ward → Community

## Rules

1. No invented LGA, ward, or community names or codes.
2. Prefer official or licensed open datasets with clear licence.
3. Every subset carries datasetName, publisher, version, retrievedAt, licence, coverageNotes.
4. Support 36 states + FCT (see states-ng.v1.json).
5. LGA/ward progressive; incomplete coverage must be explicit.

## v1 product behaviour

Keep free-text state/lga on Mandate for compatibility. Normalize later against canonical names.
