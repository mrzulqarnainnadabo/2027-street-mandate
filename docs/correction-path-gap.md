# Correction / unpublish path — known gap

**Status:** Documented gap (not implemented as a full product workflow)

## Mandates (Published)

Today operators change Notion **Status** (e.g. Published → Rejected/Flagged) as an operational control. There is **no** citizen-facing version history, correction notice, or immutable snapshot UI.

Preferred future model (not built):

1. Keep original Published text visible or archived
2. Attach correction notice + timestamp + reason
3. Require human review for unpublish
4. Audit trail in operator tools

Until then: treat Status changes as operator-only, rare, and logged outside the public wall narrative.

## Blueprints (Published)

Code locks ordinary review mutations when Published. A controlled unpublish/cleanup path exists for the synthetic pilot. Real political records must not be silently rewritten.

**LEGAL REVIEW REQUIRED** before any automated unpublish of attributed political claims at scale.
